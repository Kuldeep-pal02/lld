1)Creational Patterns
Singleton – One instance per class.
Factory Method – Create objects without exposing the instantiation logic.
Abstract Factory – Create families of related objects.
Builder – Construct complex objects step-by-step.
Prototype – Clone existing objects.

2. Structural Patterns
Adapter – Bridge between incompatible interfaces.
Bridge – Separate abstraction from implementation.
Composite – Tree structure of objects.
Decorator – Add responsibilities dynamically.
Facade – Simplified interface for a complex system.
Flyweight – Share objects to reduce memory.
Proxy – Substitute or placeholder for another object.

3. Behavioral Patterns
Chain of Responsibility – Pass request along a chain of handlers.
Command – Encapsulate a command request.
Interpreter – Grammar representation and interpreter.
Iterator – Sequential access without exposing the underlying structure.
Mediator – Reduce coupling between classes.
Memento – Capture and restore an object’s state.
Observer – Notify multiple objects of state changes.
State – Change behavior based on state.
Strategy – Select algorithm at runtime.
Template Method – Define a skeleton and let subclasses fill in the steps.
Visitor – Separate algorithm from object structure.
