Parking lot Requirements-

Functional Req:
1) Entrance and Exit - multiple entry and exit
2) Vehicle Parking - park, un-park
3) Vehicle types - car bike buses
4) Parking spots - Handicapped, small medium large electric.
5) Ticketing - issue a tkt, calculate the fare accept the payment
6) Slot allocation - nearest available suitable based on vehicle
7) Admin Feature - add/remove floors/slots/ dashboards

NFR :
Scalable, Concurrency, Performance, Extensibility

Extensibility - is must in an LLD.
